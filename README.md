# Flappy Bear

A Flappy Bird clone in vanilla JavaScript, HTML canvas and CSS. I wrote this when I was first learning JavaScript and object-oriented basics, and uploaded it a couple of years later for the record.

The later rewrite with accounts and leaderboards is [Astro-Bird](https://github.com/nydonidd/Astro-Bird).

## Running

Open `index.html` in a browser, or:

```bash
npm install
npm run dev
```
